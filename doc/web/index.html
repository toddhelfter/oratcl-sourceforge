Introduction

The Oratcl package is a dynamic extension of the Tcl language that integrates Oracle OCI calls into a set of Tcl commands that allow Oracle access via Tcl.

Starting in May 2000, Todd Helfter became the new maintainer of the Oratcl package. Oratcl 5.0 is the current supported version, for use with Oracle 23c (and earlier releases via the Oracle Instant Client). The older Oratcl 4 line supports Oracle 8i through 11g, and Oratcl 3 supports Oracle 7 and 8.0.x.

Please visit the project page for feature requests, bug reports and general help requests.

Some information

Oratcl was originally written by Tom Poindexter and his site has many valuable references. His website link can be found in the "Offsite Links" section.

Oratcl 5.0 is a full port to Tcl 9 (remaining source-compatible with Tcl 8.6), targeting Oracle 23c. It adds a new oralob2 command for direct OCI-based LOB access, and includes several security hardening fixes (see the Change History for details).

Oratcl is not linked with Oracle libraries at build time. Oracle libraries are dynamically loaded at run time, allowing the user to have flexibility of Oracle client installs.

The Oratcl 4.x and 5.x series have been released under a 'BSD' style license, which means that it can be used in commercial applications.

Prebuilt 5.0 binaries are available for macOS (Apple Silicon) and Windows x64 (the Windows build is cross-compiled with the free mingw-w64 toolchain — no MSVC or Oracle SDK required to build). A source tarball is available for Linux and other Unix-like platforms.
